# BUYAKA PUMA SMART ASSISTANT 2.0 — Demo

This is a standalone prototype located in `smart-assistant-2/`. It does not modify the existing application's root entry point.

## Preview locally
Open `index.html` in a browser.

## Deploy as a separate Vercel project
Create a **new** Vercel project from the same GitHub repository and set **Root Directory** to `smart-assistant-2`. Keep the existing BUYAKA PUMA SMART ASSISTANT project unchanged.

## Current demo scope
- Executive Light responsive dashboard
- Clickable navigation for the planned modules
- Sample KPI dashboard and illustrative charts
- Interactive task checklist
- Demo AI Manager chat with sample responses
- Sample report and product lookup interactions

## Important
All displayed figures and example staff/product rows are illustrative demo data, not live BUYAKA store data. The chat is not connected to a real AI model or store database yet. This prototype has no authentication and must not be treated as a private production system until server-side sign-in and access controls are implemented.
